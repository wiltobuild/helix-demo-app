# helix-demo-app

A tiny checkout library that [Helix](https://github.com/wiltobuild/helix)'s agents work on
in the demo. Money is whole cents throughout.

- `src/cart.ts`: cart subtotal, shipping, and total.
- `src/receipt.ts`: plain-text receipt.

```sh
npm install
npm run ci   # format check, typecheck, tests
```
